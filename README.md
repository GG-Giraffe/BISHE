# BISHE

毕业设计项目：卡牌回合制交易战斗。Unity 版本 **2022.3.62f3c1**。

把 `Player`、`Guest`、`Antique` 放在 `TradePlayCanvas` 下的站位里才能显示。站位、手牌区和倒计时都可以在编辑器里用 Rect Tool（T）拖动。

## 怎么打开

常用菜单：

- **TradePlay → 创建角色站位**：在画布上放玩家、古玩、客人的固定位置
- **TradePlay → 创建牌区和倒计时**：手牌区域和倒计时
- **TradePlay → 卡牌配置工具**
- **TradePlay → Buff配置工具**

手牌牌库填在 `HandArea` 上 `CardZone` 的 **Starting Deck**。客人的初始倒计时填在客人预制体的 **Initial Countdown**。下一回合攻击数字填在 **Intent Attack Value**。

## 回合

玩家回合一开始抽 5 张牌，并显示客人下一回合的意图。向上拖拽手牌打出。按下结束回合后，先弃掉剩余手牌，再扣倒计时，然后进入客人回合。

客人回合会隐藏意图，并按隐藏前显示的攻击数值对玩家造成一次伤害，停顿后回到玩家回合。

回合标题和战斗日志在 `TradePlayCanvas` 上。

## 牌区

牌分成牌库、手牌、弃牌堆。战斗开始时洗牌。抽牌从牌库顶入手牌，手牌上限 10 张。牌库空了就把弃牌堆洗回去。打出的牌进入弃牌堆。卡牌效果里的「弃牌」从手牌最右边开始丢。

## 效果队列

打出的卡牌效果按配置顺序逐条结算。当前会真正执行的是：

- **伤害**：先扣护盾。打在玩家身上加压力，打在客人身上加兴趣。
- **回复**：不看护盾，只降低玩家压力，最低到 0。客人暂不处理回复。
- **获得护盾**
- **抽牌**、**弃牌**、**增加倒计时**

施加 Buff、播放特效、获得费用仍只写进日志。

玩家压力达到上限时，后面的效果停止，战斗失败。

## 倒计时

倒计时是单独界面，底图一直显示。初始剩余回合数跟客人走。

- 打出牌时扣除该卡的「倒计时消耗」，再结算这张牌的效果。同一张牌可以先扣到 0，再被「增加倒计时」加回来。
- 结束回合的扣除从 1 开始，每按一次多 1。按钮上会显示本次扣除，例如「结束回合 -1」。
- 先弃光手牌再扣倒计时。扣完仍为 0 才弹出交易失败，并且不进入客人回合。

## 客人、玩家和古玩

客人兴趣打满当前阶段就进入下一阶段，溢出点数带入新阶段。每一段用客人身上的同一个阶段上限。已经在最后一段时，兴趣条停在满格，多出来的点数每点给古玩加 1% 涨价。

未到阶段上限时，涨价百分比 = 当前段数 × 每段涨价百分比。当前售价 = 基础价格 × (100 + 涨价百分比) / 100。

玩家压力、客人兴趣和双方护盾会在结算时立刻改到预制体上。护盾为 0 时护盾区隐藏。客人名字在运行时鼠标悬停才显示。

## Buff 配置

菜单 **TradePlay → Buff配置工具**，资源在 `Assets/Data/Buffs`。配置规则已经定下，但还没有接到战斗结算里：

- 平时按层数修改这一下的数值，触发时再执行一串效果。层数同时乘到加成和效果数值上。
- 持续回合在持有者自己的回合结束时减 1。先触发「回合结束」，再减回合。还剩 1 回合的 Buff 这一次仍会触发。
- 再次施加同一个 Buff 时，层数加 1，持续回合刷新成这次的新回合数。
- 触发时机：回合开始、回合结束、造成伤害时、受到伤害时、获得护盾时。

战斗和 Buff 打算分开：战斗只发出发生了什么，Buff 自己改数值、减回合，并把要执行的效果送回队列。这层运行时还没写。
